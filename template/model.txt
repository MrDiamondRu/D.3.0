Таблицы:

Организации
1)	ID в системе (присваивается как порядковый номер при добавлении новой организации в систему);
2)	Наименование организации (текстовое поле);
3)	ИНН (текстовое поле);
4)	Тип организации (выпадающий список, содержит варианты: ОРИ, хостинг, источник ЕИАС, оператор связи);
5)	Статус (требуется действие, не требуется действий, завершено взаимодействие);
6)	№ Дела (текстовое поле);
7)	Ответственное лицо (текстовое поле);
8)	Наличие в реестре (текстовое поле);
9)	Ссылка на запись в реестре (кликлабельная ссылка на карточку в реестре);
10)	Сайт (текстовое поле);
11)	Адрес для корреспонденции  (текстовое поле);
12)	Дата создания (dd.mm.gggg);
13)	Дата последнего изменения (dd.mm.gggg);
14)	Кто изменил (логин авторизованного лица, вносившего изменение).

Создаваемая система должна предусматривать корректировку значений выпадающего списка.
 От значения, указанного в поле «тип организации» зависит, набор опциональных связанных таблиц.


Объект взаимодействия:
1)	дата добавления (dd.mm.gggg);
2)	ID в системе (присваивается как порядковый номер при добавлении новой записи в систему);
3)	ID связанной организации;
4)	начало действия  (dd.mm.gggg);
5)	завершения действия  (dd.mm.gggg);
6)	вид объекта (выпадающий список: сайт, приложение, лицензия хостинг, лицензия ПД, лицензия ТФОП);
7)	объект взаимодействия (наименование сайта, ресурса, номер лицензии);
8)	ссылка на объект (URL на внешний источник).

Контакты:
1)	дата добавления (dd.mm.gggg);
2)	добавил (логин авторизованного лица, создавшего контакт);
3)	ID в системе (присваивается как порядковый номер при добавлении новой записи в систему);
4)	ID связанной организации;
5)	должность (текстовое поле);
6)	фамилия (текстовое поле);
7)	имя (текстовое поле);
8)	отчество (текстовое поле);
9)	телефонный номер (текстовое поле, с автопроверкой наличия 11 цифр без доп символов);
10)	адрес электронной почты (текстовое поле, с автопроверкой на соответствие маске АЭП *@*.*);
11)	дополнительная информация (текстовое поле).

ПСИ:
1)	дата назначения (dd.mm.gggg);
2)	ID в системе (присваивается как порядковый номер при добавлении новой записи в систему);
3)	ID связанной организации;
4)	ответственный (выпадающий список пользователей системы)
5)	дата начала (dd.mm.gggg);
6)	дата завершения (dd.mm.gggg);
7)	статус (выпадающий список: назначен, в работе, успешное завершение, провалены, просрочены)
8)	ссылка на HTML документ в локальной сети (протокол ПСИ);
9)	комментарий (текстовое поле).

Комментарии:
1)	ID в системе (присваивается как порядковый номер при добавлении новой записи в систему);
2)	ID связанной организации;
3)	автор (логин авторизованного лица, вносившего изменение);
4)	текст комментария  (текстовое поле);
5)	дата, время комментария (dd.mm.gggg hh:mm).

Событие:
1)	дата создания записи (dd.mm.gggg);
2)	ID в системе (присваивается как порядковый номер при добавлении новой записи в систему);
3)	Событие (выпадающий список: совещание, встреча, созвон); 
4)	ID связанной организации;
5)	ID связанного контакта;
6)	инициатор (логин авторизованного лица, создавшего событие);
7)	ответственный (выпадающий список пользователей системы);
8)	дата события (dd.mm.gggg);
9)	статус (выпадающий список: запланировано, состоялось, не состоялось).
10)	комментарий (текстовое поле).

Документы:
1)	дата добавления документа (dd.mm.gggg);
2)	ID в системе (присваивается как порядковый номер при добавлении новой записи в систему);
3)	ID связанной организации;
4)	добавил (логин авторизованного лица, добавившего документ);
5)	начало действия (dd.mm.gggg);
6)	завершение действия (dd.mm.gggg);
7)	документ (выпадающий список: протокол, акт, соглашение, письмо, инструкция, информационная модель и т.д.);
8)	номер документа;
9)	наименование документа (текстовое поле, содержит наименование загруженного (сохранённого) документа;
10)	ссылка на HTML документ в локальной сети (при наличии);
11)	ссылка на текстовый документ в локальной сети (при наличии);
12)	комментарий (текстовое поле).
